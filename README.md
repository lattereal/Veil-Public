# Veil Downloads

Welcome to the official download repository for **Veil**.

Veil is a privacy-focused messaging application built around end-to-end encryption.

## Download

Get the latest Windows installer from the [Releases](https://github.com/lattereal/veil-downloads/releases/latest) page.

## Installation

1. Download `Veil-Setup.exe` from the latest release.
2. Run the installer.
3. Follow the installation instructions.

## Updates

New versions and release notes are published on the [Releases](https://github.com/lattereal/veil-downloads/releases) page.

---

This repository is exclusively for distributing official Veil builds. The application source code is maintained separately.
